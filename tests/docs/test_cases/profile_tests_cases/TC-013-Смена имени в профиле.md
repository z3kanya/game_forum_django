## ТС-013: Обновление профиля - смена имени

### Предусловия: 
- Пользователь авторизован (получен валидный токен через `/api/core/login/`).

### Шаги:
1. Получить токен (POST `/api/core/login/`).
2. Выполнить PATCH-запрос `/api/core/profile/update/`
   - Заголовок: `Authorization: Bearer <токен>`
   - Тело: `{ "first_name": "Тестовый" }`
3. Проверить ответ.

### Ожидаемые результаты:
- статус 200
- в ответе обновленные данные, first_name: "Тестовый"
