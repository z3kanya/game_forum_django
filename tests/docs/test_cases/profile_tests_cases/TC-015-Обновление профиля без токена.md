## ТС-015: Обновление профиля без авторизации 

### Предусловия:
- Пользователь не авторизован.

### Шаги:
1. Выполнить PATCH-запрос `/api/core/profile/update/`
   - Тело (JSON): `{ "first_name": "Хакер" }`
   - Без заголовка Authorization.


### Ожидаемые результаты: 
- статус 401
- в ответе сообщение о том, что нет учетных данных
