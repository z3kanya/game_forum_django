## ТС-014: Обновление профиля - загрузка аватара

### Предусловия:
- Пользователь авторизован (токен получен).

### Шаги:
1. Получить токен (POST `/api/core/login/`).
2. Подготовить изображение (например, небольшой JPEG/GIF).
3. Выполнить PATCH-запрос `/api/core/profile/update/`
   - Заголовок: `Authorization: Bearer <токен>`
   - Тело (multipart/form-data): поле `avatar` с файлом изображения.
4. Проверить ответ.

### Ожидаемые результаты: 
- статус 200
- в ответе обновленные данные, avatar: "ссылка на картинку"
