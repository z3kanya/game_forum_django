## TC-017: Поиск игры по названию

### Предусловия:
- Существует зарегистрированный пользователь (например, `testuser2` / `TestPass123`).
- Получен валидный JWT access-токен для этого пользователя.

### Шаги:
1. Выполнить POST-запрос `/api/core/login/` с телом:
   `{ "username": "testuser2", "password": "TestPass123" }`
2. Из ответа извлечь поле `token`.
3. Выполнить GET-запрос `/api/games/list/` с заголовком:
   Authorization: Bearer <токен_из_шага_2>
   Params: 
   key=`search`, value=`gta`
4. Проверить статус-код и тело ответа.

### Ожидаемые результаты:
- статус 200
- в ответе список игр, названия которых содержат слово `gta`.
