## ТС-008: Несуществующий пользователь при входе

### Предусловия:
- Пользователь с `username=nonexistentuser` отсутствует.

### Шаги:
1. POST `/api/core/login/`
2. Тело:
   {
       "username": "nonexistentuser",
       "password": "123"
   }

### Ожидаемые результаты: 
- статус 401
- в ответе ошибка, говорящая, что введено неправильное имя пользователя или пароль
