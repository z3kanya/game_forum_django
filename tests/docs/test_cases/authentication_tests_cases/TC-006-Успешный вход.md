## ТС-006: Успешный вход с корректными данными

### Предусловия:
- В системе существует пользователь `testuser2` с паролем `TestPass123`.

### Шаги:
1. Выполнить POST-запрос `/api/core/login/`
2. Тело:
   {
       "username": "testuser2",
       "password": "TestPass123"
   }

### Ожидаемые результаты: 
- статус 200
- в ответе id пользователя, username, почта, дата/время регистрации и токен
