## ТС-007: Неверный пароль при входе

### Предусловия:
- Пользователь `testuser2` существует.

### Шаги:
1. POST `/api/core/login/`
2. Тело:
   {
       "username": "testuser2",
       "password": "WrongPass123"
   }

### Ожидаемые результаты: 
- статус 401
- в ответе ошибка, говорящая, что введено неправильное имя пользователя или пароль
