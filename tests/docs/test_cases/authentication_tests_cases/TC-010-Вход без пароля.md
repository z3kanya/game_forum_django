## ТС-010: Отсутствует поле пароль

### Предусловия:
- В системе существует пользователь `testuser2`

### Шаги:
1. POST `/api/core/login/`
2. Тело (без поля `password`):
   {
       "username": "testuser2"
   }

### Ожидаемые результаты:
- статус 400
- в ответе ошибка "введите имя пользователя и пароль"
