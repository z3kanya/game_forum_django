## ТС-001: Успешная регистрация

### Предусловия: 
- Пользователь с данными `testuser3` / `test3@example.com` не существует в системе.

### Шаги:
1. Выполнить POST-запрос `/api/core/register/` с телом:
2. Body:
   {
       "username": "newuser",
       "email": "new@example.com",
       "password": "TestPass123",
       "password2": "TestPass123"
   }

### Ожидаемые результаты: 
- статус 201 
- в ответе id пользователя, username, почта, дата/время регистрации и токен
