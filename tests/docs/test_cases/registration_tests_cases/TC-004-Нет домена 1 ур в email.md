## ТС-004: Некорректный email при регистрации (нет домена первого уровня)


### Предусловия: 
- Пользователь с указанными данными отсутствует.

### Шаги:
1. POST `/api/core/register/`
2. Тело:
   {
       "username": "testuser5",
       "email": "test5@example",
       "password": "TestPass123",
       "password2": "TestPass123"
   }

### Ожидаемые результаты: 
- статус 400
- в ответе ошибка, сообщающая о некорректном email
