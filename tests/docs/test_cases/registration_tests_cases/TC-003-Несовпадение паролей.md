## ТС-003: Несовпадение паролей при регистрации

### Предусловия:
- Пользователь с `username=testuser4` и `email=test4@example.com` отсутствует.

### Шаги:
1. Выполнить POST-запрос на `/api/core/register/`
2. Тело запроса:
   {
       "username": "testuser4",
       "email": "test4@example.com",
       "password": "TestPass123",
       "password2": "TestPass321"
   }


### Ожидаемые результаты: 
- статус 400
- в ответе ошибки, говорящие что пароли не совпадают
