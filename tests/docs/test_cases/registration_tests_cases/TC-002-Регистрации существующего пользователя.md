## ТС-002: Попытка регистрации существующего пользователя

### Предусловия: 
- В системе существует пользователь `testuser2` с email `test2@example.com` (или любой другой заранее созданный).

### Шаги:
1. Выполнить POST-запрос на `/api/core/register/`
2. Тело запроса:
   {
       "username": "testuser2",
       "email": "test2@example.com",
       "password": "TestPass123",
       "password2": "TestPass123"
   }

### Ожидаемые результаты: 
- статус 400
- в ответе ошибки, говорящие что пользователь с такими данными уже существует
