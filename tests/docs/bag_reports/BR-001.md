## BR-001: Ошибка при вводе неправильного пароля при авторизации

### Серьезность: Средняя

### Шаги воспроизведения:
1. Отправить POST-запрос на `/api/core/login/` с неправильным паролем.
2. Cервер вернет статус 500 вместо 400/401

### Ожидаемые поведение: Статус 400/401

### Фактическое поведение: Сервер падает с AtrributeError
